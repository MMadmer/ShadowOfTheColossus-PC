# Roadmap — Shadow of the Colossus PC

Updated with every fix. Legend: ✅ done · 🔧 in progress · ⏳ pending

**Strategy (19/10/2026):** integrate and test the community's pull requests and forks instead of
redoing the work. Local branch `comunidade` = `main` (0.57) + integrated PRs. The equivalent fixes
I made on the `sotc` branch are left out when the community already has them (and has tested them
on hardware we do not have).
