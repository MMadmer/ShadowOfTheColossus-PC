# Shadow of the Colossus — ПК (нативный порт)

Нативный порт **Shadow of the Colossus** с PS4 (CUSA08809, европейская версия 1.01, или CUSA08034,
американская версия 1.00) на Windows.
Код игры выполняется непосредственно на CPU. Это не полноценный эмулятор: есть загрузчик и
системные функции, необходимые игре. Для GPU используется видеоядро Vulkan из форка
shadPS4 SotC. Основа — [bloodborne_pc](https://github.com/Supermedo/bloodborne_pc) (GPL-2.0).

Этот пакет **не содержит ни игры, ни прошивки Sony**. У вас должны быть свои.

## Требования

- Windows 10/11 64-bit и видеокарта с Vulkan 1.3.
- Для `SotC.exe` Python не нужен; [Python 3](https://www.python.org/downloads/) требуется только
  для `SotC.bat`.
- **Ваш собственный дамп** игры CUSA08809 (европейская 1.01) или CUSA08034 (американская 1.00)
  (папка с `eboot.bin`, `sce_module`, `sce_sys`...).
- Необязательно: расшифрованные `libSceNgs2.sprx` и `libSceUlt.sprx` с **вашей собственной
  консоли**, чтобы звук использовал библиотеку консоли вместо библиотеки порта. Это те же файлы,
  что и в папке `user/sys_modules` shadPS4; на PS4 с GoldHEN они находятся в
  `/system/common/lib/`.

## Как играть

1. Откройте `SotC.exe` — программу запуска.
2. При первом запуске она **сама ищет** на дисках ПК:
   - папку игры (CUSA08809 или CUSA08034);
   - сохранение игры в shadPS4, которое она предложит импортировать;
   - DLC игры (папку `addcont` shadPS4 или папку с отдельной подпапкой для каждого DLC).
3. Проверьте результат в разделе **Игра и сохранения**. **Библиотека игр** работает так же, как в
   shadPS4: добавьте папки, в которых находятся ваши игры, и выберите игру в списке (двойным
   щелчком). **Искать на этом ПК** повторяет автоматический поиск.
4. Нажмите **ИГРАТЬ**.

Экран **Играть** сначала всё проверяет: версию игры, звуковые модули, сохранения и видеокарту.
При первом запуске подготавливается образ игры, что занимает несколько секунд. Это повторяется
только при изменении игры или модулей. Сохранения и кэш шейдеров хранятся в `user/`.

Без программы запуска то же самое делает `SotC.bat`, читая `sotc.ini`. `SotC.exe --play` сразу
запускает игру с последними параметрами программы запуска, что удобно для ярлыков и для Steam.

## Изображение и производительность

Всё это находится в программе запуска на странице **Изображение и FPS** (а основные параметры —
на странице **Играть**):

- **Вывод** 720p, 1080p, 1440p или 4K. Игра рендерит в 1080p, как на PS4, а изображение
  масштабируется до разрешения вывода с помощью **FSR 1** + повышение резкости (RCAS) или
  билинейной фильтрации. Окно никогда не превышает 90% экрана; полноэкранный режим использует
  весь монитор.
- **60 FPS** (экспериментально): снимает ограничение игры в 30 FPS (патч GoldHEN от illusion),
  с vblank 120 Гц. Измерено 38 FPS в открытом поле и ~25 в храме.
- **Повторное использование привязок** (по умолчанию выключено начиная с 0.60.6;
  `SOTC_FAST_BIND=1` включает): пропускает повторную сборку дескрипторов, если следующий вызов
  отрисовки использует тот же конвейер, ресурсы и uniform-переменные. Измерено в Святилище:
  ~25 → 30 FPS. В 0.60.5 оставляло чёрные точки сеткой на песчаной земле; исправление ожидает
  проверки.
- **Чёткие текстуры**: анизотропная фильтрация 16x, почти без затрат.
- **Режим PS4 Pro**: игра считает, что запущена на PS4 Pro, и предлагает в собственном меню
  (Параметры > Отображение) графический режим **Кинематографический** (1440p, больше деталей) или
  **Производительность**. Он тяжелее: ~25 FPS в открытом поле.
- **Эффекты**: виньетку, атмосферный туман и фоновое затенение (SSAO) можно отключить.
  Размытие в движении, яркость и фильтры находятся в меню самой игры.
- **Переменные движка (cvars)** (Дополнительно): переменные движка Bluepoint, `ИМЯ=значение`, для
  желающих поэкспериментировать.

Режимы патчей действуют для европейской версии 1.01 и американской 1.00 (исполняемый файл у них
одинаковый); в других версиях они не применяются. У каждой версии свои сохранения
(`user/savedata/1/CUSA08809` или `CUSA08034`), и она использует только DLC того же региона.

## Управление

**Мышь:** щёлкните в окне игры, чтобы захватить мышь, после чего она вращает камеру; Esc или
переключение на другое окно освобождает мышь. Левая кнопка = R1 (хвататься), правая = □
(атаковать), средняя = L1. Чувствительность и инверсия настраиваются в разделе **Управление**
программы запуска. Чтобы переназначить кнопки мыши, используйте
`mouse.<вход>=left,right,middle,x1,x2`.

Геймпад (DualShock 4, DualSense, Xbox...) используется автоматически. Если подключено несколько,
выберите один в разделе **Управление** программы запуска (или `BB_GAMEPAD=` в `sotc.ini`).
Клавиатура работает вместе с геймпадом:

| Клавиатура | PS4 |
|---|---|
| W A S D | левый стик |
| стрелки | правый стик (камера) |
| Пробел | ✕ |
| Левый Shift | ○ |
| E | □ |
| Q | △ |
| 1 / 3 | L1 / R1 |
| R / F | L2 / R2 |
| Z / C | L3 / R3 |
| Enter | Options |
| I J K L | крестовина |
| Tab / Backspace | сенсорная панель (слева / справа) |

Клавиши можно изменить в разделе **Управление** программы запуска: щёлкните действие и нажмите
новую клавишу. Геймпад и мышь также можно переназначить в `sotc.ini`, например `pad.circle=b`.
Доступные входы:

- кнопки: `cross circle square triangle l1 r1 l2 r2 l3 r3 options touchpad touchpad_right`;
- крестовина: `up down left right`;
- на клавиатуре — стики: `move_up` `move_down` `move_left` `move_right` и
  `look_up` `look_down` `look_left` `look_right`.

## Состояние

Работают: логотипы, вступление, меню с текстом, загрузка сохранения, исследование верхом,
звук, геймпады DualShock, DualSense и Xbox (с иконками и вибрацией каждого из них).

Производительность измерена в демо на титульном экране, режим 60 FPS, i9-13900K + RTX 2060 SUPER:
в среднем ~67 FPS; самый тяжёлый участок (мост в каньоне) держится на 29–34 FPS. В обычном
режиме игра работает с фиксированными 30 FPS, как на PS4.

## Частые вопросы

- **DirectX 11/12?** Нет. Видеоядро (shadPS4) транслирует GPU PS4 в Vulkan; шейдеры игры
  превращаются в SPIR-V. Любая видеокарта с современной поддержкой DirectX 12 поддерживает и
  Vulkan 1.3: обновите драйвер. Режим DirectX потребовал бы переписать всё видеоядро целиком.
- **Видеокарты AMD и Intel?** Оптимизации действуют на любой видеокарте, кроме двух, которые
  автоматически включаются только на NVIDIA (периодическая отправка работы на GPU и опережающие
  чтения). В **Изображение и FPS > Отправка работы на GPU** выберите **Вкл.**, чтобы проверить их
  на AMD или Intel; если экран станет чёрным, верните **Автоматически**.

## Диагностика

Эти переменные окружения помогают исследовать проблемы:

| Переменная | Действие |
|---|---|
| `SOTC_FPS=1` | частота кадров каждые 5 с |
| `SOTC_WINDOW_MODE=windowed/borderless/fullscreen` | окно, полноэкранное окно без рамки или эксклюзивный полноэкранный режим (в разрешении вывода) |
| `SOTC_PAD_GLYPHS=xbox/ps/keyboard` | фиксирует иконки кнопок (по умолчанию — иконки используемого устройства) |
| `BB_FAULT_RING=файл` | записывает последние исключения (сохраняется после вылетов) |
| `BB_STACKS_TRIGGER=файл` | создание файла сбрасывает стеки потоков |
| `BB_READBACKS=0/1/2` | чтения GPU; значение по умолчанию 2 требуется игре |
| `SOTC_FAST_BIND=1` | повторно использует привязки дескрипторов между одинаковыми вызовами отрисовки (по умолчанию выключено начиная с 0.60.6) |
| `SOTC_RECORD_THREAD=0` | записывает команды Vulkan в самом потоке команд (по умолчанию — в отдельном потоке) |
| `SOTC_INDIRECT_DIRECT=0` | оставляет косвенными вызовы отрисовки, аргументы которых находятся на CPU |
| `SOTC_WAIT_MARKER=1/2` | ожидания GPU опрашивают записываемый им маркер (экспериментально) |
| `SOTC_CMD_STATS=1/2` | вызовы отрисовки и dispatch-вызовы за кадр (2: самые используемые вычислительные шейдеры) |
| `SOTC_TSC=qpc/native` | часы игры: `qpc` всегда использует QPC Windows, `native` — всегда TSC процессора (по умолчанию QPC только когда ядра расходятся в показаниях TSC) |
| `SOTC_UI_HIRES=0` | с DLSS интерфейс (тексты, логотипы, HUD) снова рисуется в разрешении рендеринга и масштабируется, а не в разрешении вывода |
| `SOTC_FG_MARK=1` | FSR 3: пурпурный квадрат в левом нижнем углу сгенерированных кадров и голубой — на кадрах игры, показанных вместо них (для различения кадров в записях экрана) |
